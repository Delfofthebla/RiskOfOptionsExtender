#### 1.1.0

**Changed**
- Setting names next to a number box, slider or dropdown now use the room up to that control, instead of wrapping halfway across the row.

**Fixed**
- Settings with a button no longer squash their name into a column one letter wide.
- Long setting names no longer spill out of their row when a word only just barely doesn't fit on its line.

#### 1.0.1

Updated for the Hallowed Concepts update. No noticeable issues or need to actually upgrade, tbh.

**Changed**
- The settings menu does a lot less work every time it opens, so big modpacks should get less of a hitch when you open it.
- Reopening the All Tabs list on the same mod is quicker.

**Fixed**
- Mods that write their own description for the mod list get to keep it. It was being swapped out for the mod's Thunderstore description.
- If a mod creates another config file after you've already opened the settings menu, those settings no longer end up mixed into one of its other tabs.
